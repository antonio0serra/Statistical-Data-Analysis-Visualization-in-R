This repository contains various data analysis and visualization projects developed in RStudio using ggplot2 and the tidyverse ecosystem  
Statistical Distribution Analysis (Q-Q Plots): Generated and compared theoretical distributions (Normal vs. Cauchy) against simulated data using custom Q-Q plots.
Time-Series & Economic Trends: Cleaned and transformed datasets (CSV, Excel) to visualize metrics such as fuel price YoY variations and climate pressure changes.
Multivariate & Health Data Visualization: Created boxplots and multi-category bar charts for medical datasets (e.g., hepatitis/fibrosis categories, wine quality metrics) and EU industry statistics.
